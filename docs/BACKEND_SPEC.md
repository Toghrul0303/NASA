# BACKEND_SPEC.md — SPHEREx Sky Explorer Backend

**Spec version:** `1.0.0` (Canonical v1)
**Conforms to:** `DATA_CONTRACT.md` v`1.0.0`. Section references of the form `§C x.y` point into that file. Schemas, binary layouts, REST payloads and SSE payloads are defined only there and are not repeated here.
**Normative keywords:** MUST, MUST NOT, SHOULD, MAY as in RFC 2119.

---

## 1. Responsibilities

The backend:

1. Runs one pipeline (`discover → fetch_process → aggregate → gaia → export`) that turns SPHEREx Level 2 cutouts and Gaia DR3 sources into the files of `§C 2`.
2. Runs that pipeline offline for Tier 1 / Tier 1.5 targets (CLI) and on demand for Tier 2 coordinates (HTTP job).
3. Serves `/data/{slug}/` (`§C 13`), `POST /api/jobs` (`§C 11`) and `GET /api/jobs/{job_id}/events` (`§C 12`).
4. Is the only component that calls IRSA and ESA services. Browsers never call them.

The pipeline code path is identical for every tier. Tier 1 and Tier 1.5 differ only in where the target definition comes from.

### 5.2 Time and position (`timeutil.py`)

```python
def mjd_to_year(mjd: float) -> float                      # 2000.0 + (mjd - 51544.5) / 365.25
```

`propagate` is the only implementation of `§C 3.1`. `mjd_to_iso_utc` rounds to the nearest millisecond. RA is wrapped into `[0, 360)`.

### 5.3 Grid (`grid.py`)

```python
@dataclass(frozen=True)
class Grid:
    size_deg: float; width: int; height: int
    crval1_deg: float; crval2_deg: float
    crpix1: float; crpix2: float; cdelt1_deg: float; cdelt2_deg: float

    @staticmethod
    def build(size_deg: float, center_ra: float, center_dec: float) -> "Grid"   # §C 3.2
    def world_to_pixel(self, ra, dec) -> tuple[float, float]    # numpy implementation of the §C 3.2 equations
    def pixel_to_world(self, x, y) -> tuple[float, float]       # inverse gnomonic projection
    def to_astropy_wcs(self) -> astropy.wcs.WCS                 # TAN, CTYPE RA---TAN / DEC--TAN, used by reproject
```

Rules: `width = height = 2 * ceil(size_deg * 3600 / (2 * 6.15))`. Array shape is `(height, width)`; `y = 0` is the southern row (the astropy WCS built from `crpix`, `cdelt` orients rows this way). A unit test asserts `world_to_pixel` equals the astropy WCS result to 1e-6 px over the grid.

### 5.4 Channels (`channels.py`)

`resources/channels.json` holds the 102 rows of `meta.channels` (`§C 5.1`). It is generated once by `spherex channels build` (§10) from the SPHEREx `SPECTRAL_CHANNELS` table and committed. The pipeline refuses to start when the file is missing or does not contain 102 rows ordered by `channel`.

```python
def nearest_channel(lambda_um: float) -> int                     # §C 3.3: argmin |lambda_c - lambda|, ties -> lower index
def valid_channels() -> list[int]                                # [0..49] + [52..101]
def feature_lines() -> list[FeatureLine]                         # §C 7.3 item 8
```

### 5.5 Contract helpers (`binfmt.py`)

```python
def pack_item(intensity: np.ndarray, sigma: np.ndarray, f16_max: float = 65504.0) -> tuple[bytes, int]
def unpack_item(buf: bytes, height: int, width: int) -> tuple[np.ndarray, np.ndarray]
```

`pack_item` (inputs `float32`/`float64`, shape `(H, W)`):

1. Enforce `sigma[~isfinite(intensity)] = nan` and `intensity[~isfinite(sigma)] = nan`, then replace ±Inf with NaN.
2. Count finite values whose magnitude exceeds `f16_max` over both planes (the returned `saturated` count) and clip them to ±`f16_max`.
3. Convert with `astype("<f2")` (round-to-nearest-even) and concatenate plane 0 then plane 1 in C-order (`§C 10.1`).
4. NaN is written as `0x7E00` (numpy's default float16 NaN).

A test decodes the 16-byte vector of `§C 10.3` with `unpack` and `numpy` and checks the expected values.

## 6. Pipeline

### 6.1 Entry point (`pipeline.py`)

```python
class EventSink(Protocol):
    def emit(self, event: str, payload: dict) -> None: ...      # payloads per §C 12.3, without `job_id`; the sink adds it

@dataclass
class PipelineOutcome:
    slug: str
    result_status: Literal["complete", "partial"]
    data_version: str
    n_frames: int
    n_epochs: int
    n_failed_fetches: int
    files: dict[str, dict]       # §C 12.3 `complete.files`, including meta.json
    elapsed_s: float

def run_pipeline(target: Target, sink: EventSink, deadline: float | None = None) -> PipelineOutcome
```

`run_pipeline` raises `PipelineError(code, message, retryable)` with `code` in `no_coverage`, `upstream_unavailable`, `timeout`, `internal_error` (`§C 12.3 failed`). Tier 1 / Tier 1.5 CLI builds use `run_pipeline` with a console sink.

### 6.2 Stage flow

| # | Stage event (§C 12.2) | Work |
|---|---|---|
| 1 | `discover` | TAP discovery, release filter, de-duplication, `t_mid`, Gaia query and proper-motion adoption, final center and grid, `discovery` event |
| 2 | `fetch_process` | Per exposure: fetch, parse, calibrate, photometry, reproject, centroid, `frame` event. One backfill pass for failures |
| 3 | `aggregate` | Sort and index frames, epochs, channel assignment, coadds, RGB presets, alignment residuals, `sed.json` model |
| 4 | `gaia` | Proper-motion fit, consistency, verdict, predicted tracks, `gaia.json` model |
| 5 | `export` | Pack binaries, write JSON and PNG, validate, write `meta.json` last, publish atomically |

Each stage emits `stage(started)` and `stage(finished)` with `elapsed_s` measured from the start of the run. Events follow the order of `§C 12.2`.

### 6.3 Stage 1 — Discovery (`targets.py`, `discovery.py`, `gaia.py`)

#### 6.3.1 Target construction (`targets.py`)

- **Tier 1** target: built from `tier1_targets`. `resolve: gaia` entries read `paths.resolved_targets_file` (written by `spherex targets resolve`, §10). Entries with an explicit position and `pm` use those values (`pm_source = "literature"`, `pm_reference` from config). A missing resolved entry is a startup error for that slug.
- **Tier 1.5** target: explicit `ra_deg`, `dec_deg`; `coord_epoch_year = 2000.0`, `coord_epoch_assumed = true`; no proper motion (`pm_source = "none"`).
- **Tier 2** target: built from the normalized request (`§C 11.2`). `pm_source = "user"` when both proper motions are supplied, otherwise `"none"` until the Gaia step (§6.3.4) may adopt Gaia's.

#### 6.3.2 TAP discovery (`discovery.py`)

```python
class DiscoveryClient(Protocol):
    def query(self, ra_deg: float, dec_deg: float) -> list[TapRow]: ...
```

ADQL (IRSA TAP, ADQL 2.0; executed with `pyvo.dal.TAPService(irsa.tap_url).run_sync`):

```sql
SELECT a.uri, p.time_bounds_lower, p.energy_bandpassname
FROM spherex.artifact a JOIN spherex.plane p ON a.planeid = p.planeid
WHERE 1 = CONTAINS(POINT('ICRS', {ra}, {dec}), p.poly)
ORDER BY p.time_bounds_lower
```

No bandpass filter is applied. Rules:

1. The first query is placed at `propagate(target, irsa.discovery_epoch_mjd)`.
2. `base_uri = irsa.uri_prefix + uri` (an `uri` that is already absolute is used unchanged). `release` is the path component matching `irsa.release_path_pattern` for a release listed in `irsa.releases`; rows with any other release are dropped.
3. `detector` is parsed from `energy_bandpassname` (`SPHEREx-D<n>`).
4. `frame_key` is the file name stem of `base_uri`.
5. **De-duplication**: group rows by the stem prefix before `_spx_`; keep the row with the greatest `(vnum, year, doy)` parsed from `v(\d+)-(\d{4})-(\d{3})` in the remainder; ties resolve to the lexicographically greatest file name.
6. `mjd = time_bounds_lower`. A row with `mjd` outside 60000–70000 is dropped and counted as a failed frame with message `invalid mjd` (`§C 6.2`).
7. `t_mid = (min(mjd) + max(mjd)) / 2` over the de-duplicated exposures (including those later failing to fetch), so `meta.center` is reproducible from `meta.observations`.
8. The center is `propagate(target, t_mid)`. If it differs from the query position by more than `irsa.rediscovery_threshold_arcsec`, discovery is run once more at the new center; the second result is final.
9. TAP failures retry `irsa.tap_retries` times with `irsa.fetch_backoff_s * k` sleeps; exhaustion raises `PipelineError("upstream_unavailable", …, retryable=True)`. Results are cached in `cache/tap/` for `irsa.tap_cache_ttl_s`.
10. An empty result raises `PipelineError("no_coverage", …, retryable=False)`.

Each `Exposure` receives `cutout_ra_deg, cutout_dec_deg = propagate(target, mjd)` and
`source_uri = irsa.cutout_query_template.format(uri=base_uri, ra=…, dec=…, size=size_deg + 2 * irsa.cutout_margin_deg)`.

`data_version` (`§C 5.3` invariant 8) is computed here from the sorted `source_uri` values of all de-duplicated exposures.

#### 6.3.3 Gaia query (`gaia.py`)

```python
class GaiaClient(Protocol):
    def cone(self, ra_deg: float, dec_deg: float, radius_arcsec: float) -> list[GaiaRow]: ...
```

ADQL (`astroquery.gaia.Gaia.launch_job`, synchronous, anonymous):

```sql
SELECT source_id, ra, dec, ref_epoch, pmra, pmdec, parallax, parallax_error, phot_g_mean_mag
FROM gaiadr3.gaia_source
WHERE 1 = CONTAINS(POINT('ICRS', ra, dec), CIRCLE('ICRS', {ra}, {dec}, {radius_deg}))
```

The column list is fixed by `§C 9.2` item 1. Cone center is `(input_ra_deg, input_dec_deg)`. Radius (`§C 9.2` item 1):

```
radius_arcsec = gaia.static_radius_arcsec                                     if pm is null
radius_arcsec = |mu_total_arcsec_per_yr| * abs(reference_epoch_year - coord_epoch_year) + 10    otherwise
```

For `resolve: gaia` Tier 1 targets the radius is at least their `gaia_search_radius_arcsec` during resolution only (§10); builds use the rule above with the resolved proper motion. `source_id` is carried as a string. Gaia failures retry `gaia.retries` times; exhaustion sets `query_status = "unavailable"` (the job continues). The outcome (rows or failure) is kept in memory and in `cache/gaia/` for `gaia.cache_ttl_days`. The `gaia_unavailable` warning is emitted at the start of the `gaia` stage.

#### 6.3.4 Proper-motion adoption (fixed point, at most one iteration)

Applies only when `pm_source == "none"` and the Gaia query succeeded.

1. Compute separations against the current center (zero motion) and select the primary by `§C 9.2` items 2–3.
2. If the primary exists and has non-null `pmra`, `pmdec`: tentatively adopt them (`pm_source = "gaia_dr3"`, `pm_reference = "gaiadr3.gaia_source:{source_id}"`, `parallax_mas` from the source), recompute the center at `t_mid`, and recompute all separations and the primary against the new center.
3. If the primary under the new center is a different source or does not exist, revert the adoption (`pm_source = "none"`, pm and parallax null) and recompute against the static center.

The final state satisfies every invariant of `§C 5.3` and `§C 9.2`. A changed center moves the cutout centers: `Exposure.cutout_*` and `source_uri` are recomputed after this step and `data_version` is computed from the final URIs.

#### 6.3.5 Final grid and `discovery` event

After 6.3.2–6.3.4: `Grid.build(size_deg, center.ra, center.dec)`. Emit `discovery` (`§C 12.3`): `n_exposures_found` is the number of TAP rows after release filtering and before de-duplication; `n_exposures` the number of exposures to fetch; `releases` and `detectors` count `n_exposures` (detector keys are the strings `"1"`…`"6"`).

### 6.4 Stage 2 — Fetch and process (`fetch.py`, `parse.py`, `calibrate.py`, `reproject_step.py`, `photometry.py`, `centroid.py`, `frames.py`)

#### 6.4.1 Execution model

- A `ThreadPoolExecutor(max_workers=irsa.max_concurrent_fetches)` runs one *unit* per exposure. A unit is `fetch → process`.
- The module-level `FETCH_SEMAPHORE = threading.BoundedSemaphore(irsa.max_concurrent_fetches)` guards network fetches across all jobs.
- Results are stored in a dict keyed by `frame_key`; sink calls are thread-safe.
- The deadline (`jobs.job_timeout_s`) is checked between units; exceeding it raises `PipelineError("timeout", …, retryable=True)`.

#### 6.4.2 Fetch (`fetch.py`)

```python
def fetch_cutout(exposure: Exposure, cache_dir: Path, on_retry: Callable[[int], None]) -> Path
```

1. Cache path `cache/cutouts/{h[:2]}/{h}.fits` with `h = sha256(source_uri)`. A cache hit returns immediately.
2. Otherwise acquire `FETCH_SEMAPHORE` and download via `astropy.io.fits.open(source_uri, cache=False)`; write the HDUs to a temporary file and `os.replace` it into place.
3. Up to `irsa.fetch_retries` attempts. Caught: `TimeoutError`, `urllib.error.HTTPError`, `http.client.IncompleteRead`, `http.client.RemoteDisconnected`, `OSError`. After failed attempt `k` (before the last), sleep `irsa.fetch_backoff_s * k` and call `on_retry(k)` (the pipeline emits `warning fetch_retry`).
4. A downloaded file without an `IMAGE` extension is a failed attempt.
5. Exhausted retries return failure; the unit records the exposure as dropped and emits `warning fetch_failed` (`§C 12.3`).

**Backfill pass.** After all units finish, every dropped exposure is attempted once more with a full retry cycle (same rules, including events). Exposures still failing are final: they count in `n_failed_fetches` and their `source_uri` goes into `meta.observations.failed_source_uris` (at most 500).

If every exposure fails, the run raises `PipelineError("upstream_unavailable", …, retryable=True)`.

#### 6.4.3 Parse (`parse.py`)

```python
@dataclass
class ParsedCutout:
    image: np.ndarray; variance: np.ndarray; flags: np.ndarray   # (ny, nx); flags int32
    zodi: np.ndarray
    wcs: WCS                       # spatial WCS (SIP included)
    wcs_spec: WCS                  # alternate spectral WCS, key "W", .sip = None
    detector: int
    obs_id: str                    # OBSID
    version: str | None            # VERSION; None when absent/empty
    psf: np.ndarray | None

def parse_cutout(path: Path) -> ParsedCutout

def wavelength_at(parsed: ParsedCutout, x: np.ndarray, y: np.ndarray) -> tuple[np.ndarray, np.ndarray]   # (lambda_um, bandwidth_um)
```

Extensions are read by name: `IMAGE`, `FLAGS`, `VARIANCE`, `ZODI`, `PSF`, and the `WCS-WAVE` lookup tables consumed by the spectral WCS. The spectral WCS is built as `WCS(hdul["IMAGE"].header, hdul, key="W")` with `.sip = None`; its `pixel_to_world` returns the wavelength and bandwidth, converted to micrometres. Shape mismatches between the four image extensions raise a unit-level failure with message `invalid cutout` (the frame is dropped, `§C 6.2`).

#### 6.4.4 Per-frame processing (`frames.py`)

For each parsed cutout, with `α, δ = exposure.cutout_ra_deg, exposure.cutout_dec_deg` and `(xn, yn)` the native pixel of `propagate(target, mjd)` from `wcs.world_to_pixel_values`:

| Step | Rule |
|---|---|
| Target position | `target_ra_deg, target_dec_deg = propagate(target, mjd)`; `target_x, target_y = grid.world_to_pixel(...)` (`§C 6.2`) |
| Wavelength | `lambda_um`, `bandwidth_um` = `wavelength_at` at `(xn, yn)`; `lambda_min_um`, `lambda_max_um` = min and max of `wavelength_at` over the native pixels that are finite and not bad; `channel = nearest_channel(lambda_um)` |
| Flag statistics | Native pixels with distance ≤ `processing.aperture_radius_px` from `(xn, yn)` and inside the array form the aperture: `aperture_pixels = count`. For each bad bit, `flag_fractions[name] = count(flags has bit) / aperture_pixels`. When `aperture_pixels == 0`, `flag_fractions = null`. `contamination_level` per `§C 3.6` |
| Bad mask | `bad = (flags & bad_mask) != 0 or not finite(image) or not finite(variance) or variance <= 0` |
| Calibration | `I_z = image − zodi`. `B = sigma_clipped_stats(I_z[~bad & outside 5 px of (xn, yn)], sigma=3.0, maxiters=5).median` (scalar; `0.0` when fewer than 10 pixels remain). `I' = I_z − B`; `I'[bad] = nan`; `V = variance` with `bad → nan` |
| Photometry | `photometry.measure(...)` (§6.4.5) |
| Reprojection | `reproject_step.to_grid(I', V, parsed.wcs, grid)` returns `(intensity, sigma)` on the common grid: `reproject_interp` (bilinear) or `reproject_exact` per `processing.reprojection`; the same method is applied to the variance; `sigma = sqrt(V_reprojected)`; a pixel is valid only when the footprint is positive and both outputs are finite and `sigma > 0`; invalid pixels are NaN in both planes |
| Quality | `good_fraction = count(finite(intensity)) / (H * W)` (before packing) |
| Packing | `pack_item(intensity, sigma)` → `pixels_bytes`, `saturated_pixels` |
| Centroid | `centroid.measure(...)` (§6.4.6) on the packed-precision-free float32 grid arrays |
| Alignment | `alignment_residual_px = null` here; computed in the `aggregate` stage |

The result is a `FrameResult` holding the provisional frame dictionary (all `§C 6.1` frame fields except `index` and `epoch_id`), the packed bytes, the photometry and centroid results, and the float32 grid arrays (kept for coadds).

A frame with no finite pixels in `intensity` (`good_fraction == 0`) is retained in `frames.json` and `frames.bin` but excluded from coadds.

After each frame completes the sink emits `frame` (`§C 12.3`): `seq_frame` is a per-job counter from 1, `frame` is the provisional dictionary, `pixels` carries the base64 of the packed bytes with `shape = [2, H, W]`. After each frame (successful or final failure) a `progress` event is emitted subject to `jobs.progress_max_hz`; a final `progress` event with `done + failed == total` is always emitted before `stage(fetch_process, finished)`.

The first time a frame has `lambda_max_um − lambda_min_um > bandwidth_um`, emit `warning wavelength_gradient` once for the job with `context = {max_span_um, min_bandwidth_um}` (`min_bandwidth_um` is the smallest `bandwidth_um` seen across frames at that moment).

#### 6.4.5 Photometry (`photometry.py`)

```python
@dataclass
class PhotResult:
    flux_mjy: list[float | None]        # per photometry_radii_px
    flux_err_mjy: list[float | None]
    solid_angle_source: Literal["sapm", "nominal_pixel"]

def measure(i_z: np.ndarray, variance: np.ndarray, bad: np.ndarray, omega_sr: np.ndarray | float,
            xn: float, yn: float) -> PhotResult
```

Photometry runs on the native cutout (before reprojection), centered on `(xn, yn)`. For each radius `r` in `processing.photometry_radii_px` (`§C 8.2` item 2):

1. Annulus pixels: finite, not bad, `annulus_px[0] ≤ distance ≤ annulus_px[1]`. `B_ann` is their sigma-clipped mean (`processing.background_clip_sigma`, `…_iters`); `σ_B = std / sqrt(N_ann)` from the same clipped set. An empty annulus makes the result `null`.
2. Aperture pixels `A`: finite, not bad, distance ≤ `r` (pixel-center membership). An empty `A` makes the result `null`.
3. `F_MJy = Σ_A (I_z · Ω) − B_ann · Σ_A Ω`, `Ω` in sr per pixel.
4. `σ_F_MJy = sqrt(Σ_A (variance · Ω²) + (σ_B · Σ_A Ω)²)`.
5. `flux_mjy = F_MJy · 1e9`, `flux_err_mjy = σ_F_MJy · 1e9` (`1 MJy = 1e9 mJy`).
6. `flux_mjy[k]` and `flux_err_mjy[k]` are `null` together.

`Ω` comes from the solid-angle pixel map slice when `photometry.sapm.uri_template` is configured and the slice is available for every frame of the job; otherwise the constant `photometry.nominal_pixel_sr` is used for every frame. The job-wide choice is written to `sed.json.solid_angle_source` (`"sapm"` only when all frames used SAPM).

#### 6.4.6 Centroids (`centroid.py`)

```python
def measure(intensity: np.ndarray, sigma: np.ndarray, x0: float, y0: float,
            frame_index_seed: int) -> tuple[float | None, float | None, float | None]
```

On the float32 grid arrays: window = grid pixels within `processing.centroid_window_radius_px` of `(x0, y0)` that are finite. The centroid is `photutils.centroids.centroid_com` of the window after subtracting the window median and clipping negatives to 0. Uncertainty: `processing.centroid_mc_samples` Monte-Carlo realizations perturbing each pixel with Gaussian noise of its `sigma` (RNG seeded with a per-job constant plus `frame_index_seed`, the provisional arrival counter), recomputing the centroid, and taking the standard deviation (`centroid_err_px = hypot(σ_x, σ_y)`). The triple is `(None, None, None)` when fewer than 5 finite pixels remain or the clipped flux sums to 0. Coordinates are grid pixels (`§C 3.2`).

### 6.5 Stage 3 — Aggregate (`group.py`, `coadd.py`, `rgb.py`, `alignment.py`)

1. **Order and index.** Sort frames by `(mjd, detector, frame_key)`; assign `index` (`§C 6.3` invariant 1).
2. **Epochs** (`group.py`): single-linkage clustering of sorted `mjd` with gap `processing.epoch_gap_days` (`§C 3.5`); assign `epoch_id`; build the `epochs` array (`mjd_start`, `mjd_end`, `mjd_mean`, `n_frames`, sorted `detectors`).
3. **Coadds** (`coadd.py`): for each scope of `§C 7.1`, group the frames with `good_fraction > 0` and compute:

   ```
   w   = 1 / sigma²                (0 where NaN)
   Ī   = Σ(w · I) / Σw             (NaN where Σw == 0)
   σ̄  = 1 / sqrt(Σw)               (NaN where Σw == 0)
   ```

   in float64, stored as float32 for packing. Entries, ordering, `frame_indices`, `lambda_*`, `mjd_*` and `snr_target` follow `§C 7.3`; `snr_target` is evaluated at the grid position of `propagate(target, mjd_mean)`. Entries with no member frames are omitted.
4. **RGB presets** (`rgb.py`): `detector_rgb` per `§C 7.3` item 6 (enumeration of the 10 contiguous partitions, tie rules); `equal_channel_rgb` constants per item 7; `feature_lines` per item 8.
5. **Alignment residuals** (`alignment.py`): for each detector, select up to `processing.alignment_max_sources` of the brightest local maxima of that detector's `detector`-scope coadd (peak-finding via `photutils.detection.find_peaks`, excluding positions within 5 px of any frame's target position). For every frame of that detector, centroid each selected source (5×5 window, same method as §6.4.6, no uncertainty). For each source, the reference position is the median over frames. `alignment_residual_px` of a frame is the RMS of its offsets from the reference over sources with valid centroids; it is `null` when fewer than `processing.alignment_min_sources` sources are valid (`§C 6.2`).
6. **SED model** (`sed.json`, `§C 8`): one point per frame in frame order, combining the frame's index, epoch, detector, channel, time and wavelength with its photometry and centroid results; `flagged = (contamination_level != 0)`.

### 6.6 Stage 4 — Gaia products (`pmfit.py`, `gaia.py`)

1. **Predicted track.** For the primary source only: one entry per epoch with `mjd = epochs[i].mjd_mean`, position propagated from the source's `ref_epoch` with its own proper motion (zero motion when null), and grid pixel from `grid.world_to_pixel` (`§C 9.2` item 4).
2. **Measured proper motion** (`pmfit.py`): use frames with non-null centroids and `contamination_level != 2`. Convert each centroid to tangent-plane offsets `(ξ, η)` in arcsec relative to the grid center with `grid.pixel_to_world` and the gnomonic equations of `§C 3.2`. Fit `ξ(t)` and `η(t)` (`t` in Julian years from `mjd_to_year`) with weighted linear least squares, weights `1/σ²` with `σ = max(centroid_err_px, processing.pm_centroid_sigma_floor_px) · 6.15`. The slopes are `pmra_mas_yr` and `pmdec_mas_yr` (×1000, because ξ is already scaled by cos δ); the errors come from the covariance of the fit, scaled by `max(1, χ²/dof)` with `χ² = Σ w·residual²` and `dof = n_frames_used − 2` (no scaling when `dof ≤ 0`). The per-frame sigmas are Monte-Carlo and floor-limited and understate the real centroid scatter; the scaling makes the reported errors reflect the scatter about the fitted line and never makes them smaller than the formal covariance. `n_frames_used`, `n_epochs_used` (distinct `epoch_id`), `baseline_days` (max − min `mjd`) are recorded. The result is `null` when `n_epochs_used < processing.pm_fit_min_epochs` or `baseline_days < processing.pm_fit_min_baseline_days` (`§C 9.2` item 5).
3. **Consistency** (`§C 9.2` item 6): non-null only when `measured_pm` is non-null and the primary has non-null `pmra`, `pmdec`. The Gaia proper-motion errors are not selected by the contract query and are treated as 0; `sigma_combined_mas_yr = max(pmra_err_mas_yr, pmdec_err_mas_yr)` of the measurement.
4. **Verdict** (`§C 9.2` item 7). `verdict_detail` templates:

   | Verdict | `verdict_detail` |
   |---|---|
   | `unavailable` | `Gaia DR3 query was unavailable.` |
   | `no_counterpart` | `No Gaia DR3 source within 10 arcsec of the target position at the mid-observation epoch.` |
   | `match_consistent` with consistency | `Gaia source {id} matches in position and proper motion (within 3 sigma).` |
   | `match_consistent` without consistency | `Gaia source {id} matches in position; proper-motion consistency was not evaluated.` |
   | `match_inconsistent` | `Gaia source {id} matches in position but the measured proper motion differs by {d:.0f} mas/yr (above 3 sigma).` |

5. When `query_status == "unavailable"`, `gaia.json` carries the values of `§C 9.2` item 8 and `query` still records the attempted cone and ADQL with `executed_utc` of the last attempt.

### 6.7 Stage 5 — Export (`export.py`, `rgb.py`, `contract_check.py`)

Procedure (all file formats per the referenced contract sections):

1. **Staging.** Create `data/.tmp/{slug}-{uuid}/` (plus `previews/`).
2. **Binaries.** Write `frames.bin` (`§C 10.1`) by concatenating each frame's packed bytes in index order; write `coadds.bin` (`§C 10.2`) from packed coadds in coadd order (an empty file when there are no coadds). Record sizes.
3. **Previews** (`§C 5.1` `previews`, `§C 3.2` PNG orientation):
   - A reference stretch for each image: for each preview, finite pixels are normalized with `lo, hi` = `previews.lower_percentile` and `previews.upper_percentile` percentiles of the finite pixels of that preview (for RGB, of the three channels pooled so colors share a scale); `x = clip((v − lo) / (hi − lo), 0, 1)`; `y = arcsinh(a · x) / arcsinh(a)` with `a = previews.asinh_a`; NaN maps to 0. Output is 8-bit; rows are flipped so row 0 is north.
   - `thumb.png` (mode `L`): inverse-variance combination of all frames with `good_fraction > 0`.
   - `rgb_detector.png` (mode `RGB`): channels are the inverse-variance combinations of the `detector`-scope coadds of the `blue`, `green`, `red` groups of `detector_rgb`. Omitted when `detector_rgb` is `null`.
   - `rgb_equal_channel.png` (mode `RGB`): channels are the inverse-variance combinations of the `channel`-scope coadds in `blue_channels`, `green_channels`, `red_channels`. A group without coadds renders as zeros.
4. **JSON.** Build `frames.json`, `coadds.json`, `sed.json`, `gaia.json`. Writer: `json.dumps(obj, allow_nan=False, ensure_ascii=False, separators=(",", ":"))`, UTF-8, LF, no BOM; numpy scalars are converted to Python types. `slug`, `data_version` and `schema_version = "1.0.0"` are set on every file.
5. **Metadata.** Build `meta.json`: `status = "partial"` when `n_failed_fetches > 0` else `"complete"`; `created_utc = now`; `pipeline_version = __version__`; `title` from config (Tier 1 / 1.5) or the request `name` or `RA {ra:.4f}, Dec {dec:+.4f}` (Tier 2); `observations.mjd_min/mjd_max` over all de-duplicated exposures (§6.3.2 item 7), `n_frames` and `n_epochs` over the produced frames; `processing` from config (`§C 5.2` fixed values); `channels` from `resources/channels.json`; `files` with `bytes` and SHA-256 of every file except `meta.json`; `binaries` descriptors (`§C 5.1`). `meta.json` is written last.
6. **Validation.** When `export.validate` is true, run `contract_check.validate_directory` (§6.8) on the staging directory; a failure raises `PipelineError("internal_error", …)` and nothing is published.
7. **Publish.** Acquire `data/.locks/{slug}.lock`; if `data/{slug}` exists, rename it to `data/.trash/{slug}-{uuid}`; rename the staging directory to `data/{slug}`; delete the trash directory; release the lock. For Tier 2 jobs write `cache/jobs/by_slug/{slug}.json` with the producing `job_id`.
8. **Outcome.** `files` for `PipelineOutcome` and the `complete` event is `meta.files` plus the `meta.json` entry (`§C 12.3`).

## 7. Jobs and events (`events.py`, `jobs.py`)

### 7.1 Event log

```python
class EventLog:
    def __init__(self, job_id: str, dir: Path): ...
    def append(self, event: str, data: dict) -> int            # assigns id = previous + 1 under a lock, persists, notifies waiters
    def read_from(self, last_id: int) -> Iterator[tuple[int, str, dict]]
    async def wait_for(self, last_id: int, timeout: float) -> bool
    terminal: bool
```

Persistence: one JSON object per line in `cache/jobs/{job_id}/events.jsonl`: `{"id": n, "event": "...", "data": {...}}`. All events, including `frame` events, are persisted (`§C 12.1` replay). Appends are flushed before waiters are notified. Active jobs keep an in-memory index of byte offsets; finished jobs are read from disk on demand.

`data` always contains `job_id`. The event sink for a running job (`JobSink`) adds `job_id` and `timestamp_utc` where the contract requires it, throttles `progress` to `jobs.progress_max_hz`, and appends events in the order produced by the pipeline.

### 7.2 Job manager

```python
class JobManager:
    def submit(self, request: NormalizedRequest) -> SubmitResult      # §C 11.4 semantics
    def get(self, job_id: str) -> Job | None
    async def run_forever(self) -> None                               # scheduler task
    def prune(self) -> None
```

`submit`:

1. Compute `slug` (`§C 11.3`) and the Tier 2 `Target` from the request.
2. If `force_refresh` is false and `data/{slug}/meta.json` exists with `status == "complete"` and age below `jobs.cache_ttl_hours`: return `cached = true`, `status = "complete"`, HTTP 200. The `job_id` comes from `cache/jobs/by_slug/{slug}.json`. `spherex build-coord` runs with `job_id = "cli"` and does not write that file, so when it is missing, or when the recorded job's `complete` event does not carry the sha256 of the current `meta.json`, mint `job_id = "j_" + secrets.token_hex(8)`, write `job.json`, and synthesize the stream. Synthesis is `job_state(complete)` then `complete` (`§C 12.2`). `complete.elapsed_s` is `0.0`: `meta.json` does not store the original duration. `force_refresh` skips this step and starts a new job under `cfg.effective("tier2")`, including `tier2_overrides.sampling.max_frames_per_target`. That job is not limited to cutouts already on disk, so it can select more frames than an earlier cache-only build and finish `result_status = "partial"` when live fetches fail. A failed job publishes nothing.
3. Else if a queued or running job with the same `slug` exists: return it with `joined = true`, HTTP 202.
4. Else if `queued + running >= jobs.max_concurrent_jobs + jobs.queue_capacity`: raise `QueueFull` (HTTP 429, `Retry-After: jobs.retry_after_s`).
5. Else create `job_id = "j_" + secrets.token_hex(8)`, write `job.json` (request, slug, status, `created_utc`), append `job_state(queued, queue_position)` (1-based), and enqueue; HTTP 202.

`run_forever` (an asyncio task started at application startup) starts up to `jobs.max_concurrent_jobs` jobs concurrently. A job starts by appending `job_state(running)`, then runs `run_pipeline` on a daemon thread. On success it appends `complete`; on `PipelineError` it appends `failed` (`code`, `message`, `retryable`, `elapsed_s`); on any other exception it appends `failed` with `internal_error`. Terminal events mark the log terminal and close subscriber streams. `job.json` records the terminal status.

`prune` is specified as an hourly task (remove `cache/jobs/{job_id}/` more than `jobs.event_retention_hours` after the terminal event, and `data/c-*` older than `jobs.tier2_data_retention_days`) but is not started. It is M6. `spherex jobs prune` and `spherex warm` exit 3 with "not implemented".

**Startup recovery.** Every `job.json` with a non-terminal status is closed by appending `failed` (`internal_error`, message `Server restarted.`, `retryable = true`).

### 8.2 `POST /api/jobs`

1. Reject a `Content-Type` other than `application/json` with `415 unsupported_media_type`.
2. Read the raw body and parse with `json.loads`; failure → `400 malformed_json`.
3. Validate with a strict Pydantic model (`extra="forbid"`, strict types: booleans are not coerced from strings, numbers are not coerced from strings). Field rules are those of `§C 11.1` and `§C 11.2`: `ra_deg ∈ [0, 360)`, `dec_deg ∈ [-90, 90]`, `size_deg ∈ {0.05, 0.1, 0.2}`, `name` ≤ 120 characters, `coord_epoch_year ∈ [1900, 2100]` or `null`, both proper motions present or both `null`. Failures → `422 invalid_request` with `details = [{field, issue}]`, `field` being the dotted JSON field name.
4. Normalize (`§C 11.2`): defaults applied, `ra_deg` and `dec_deg` rounded to 6 decimals, `coord_epoch_year = null → 2000.0` with `coord_epoch_assumed = true`.
5. Compute the slug with exactly:

   ```python
   request_key = f"{ra:.6f}|{dec:.6f}|{size:.2f}|{pm_a}|{pm_d}|{epoch:.2f}"
   pm_a = repr(float(pmra)) if pmra is not None else "none"      # likewise pm_d
   slug = "c-" + hashlib.sha256(request_key.encode("utf-8")).hexdigest()[:16]
   ```

6. Return the `submit` result: `200` for cached, `202` otherwise (`joined` as applicable), body per `§C 11.4` with `events_url = f"/api/jobs/{job_id}/events"` and `data_base_url = f"/data/{slug}/"`; `request` is the normalized request.
7. `429` carries `Retry-After`; unexpected exceptions return `500 internal_error`.

### 8.3 `GET /api/jobs/{job_id}/events`

Response headers: `Content-Type: text/event-stream; charset=utf-8`, `Cache-Control: no-cache`, `X-Accel-Buffering: no`. Unknown `job_id` → `404 not_found`.

```python
async def stream(job, last_event_id: int):
    yield f"retry: {cfg.jobs.sse_retry_ms}\n\n"
    cursor = last_event_id
    while True:
        for (id_, event, data) in job.log.read_from(cursor):
            yield f"id: {id_}\nevent: {event}\ndata: {json.dumps(data, separators=(',', ':'), allow_nan=False)}\n\n"
            cursor = id_
        if job.log.terminal and cursor >= job.log.last_id:
            return
        if not await job.log.wait_for(cursor, timeout=cfg.jobs.sse_keepalive_s):
            yield ": keepalive\n\n"
```

Rules: `Last-Event-ID` is parsed as a non-negative integer (invalid or missing → `0`); events with `id > Last-Event-ID` are replayed in order; the stream closes after the terminal event (`complete` or `failed`) has been sent; the client disconnect is detected through `request.is_disconnected()` and ends the generator without affecting the job.

### 8.4 `/data` service

A custom route (not a generic static mount) implementing `§C 13`:

1. The slug directory must match the slug pattern and contain `meta.json`; otherwise `404 not_found` for every file in it. Path traversal is rejected with `404`.
2. `Content-Type` by extension: `.json` → `application/json`, `.bin` → `application/octet-stream`, `.png` → `image/png`.
3. `ETag: "{sha256}"` — for files listed in `meta.files` from `meta.files`; for `meta.json` computed from its bytes and memoized by `(path, mtime_ns)`. `If-None-Match` is honored with `304`.
4. `Cache-Control: public, max-age=31536000, immutable` when the query string contains `v=<data_version>` and it equals the directory's current `data_version`; otherwise `no-cache`.
5. `.json` responses are gzip-compressed when the request has `Accept-Encoding: gzip` (compressed bytes memoized by `(path, mtime_ns)`), with `Vary: Accept-Encoding`. `.bin` and `.png` are never compressed and always carry `Content-Length`.
6. `HEAD` returns the headers of the corresponding `GET`.
7. During export publication (§6.7 item 7) a request for a slug being published takes the same per-slug lock while it reads the file. `FileLock` has no shared mode, so the lock is exclusive and readers of one slug serialize for that read. A request therefore observes either the old or the new directory, never a mix of the two.

CORS: `fastapi.middleware.cors.CORSMiddleware` with `server.cors_allow_origins` (methods `GET`, `HEAD`, `POST`, `OPTIONS`; header `Last-Event-ID` allowed; `ETag` exposed).

### 8.5 Application lifecycle

Startup order: load and validate config (§4 rules) → load schemas registry → load `channels.json` → create directories → apply recovery (§7.2) → start `JobManager.run_forever`. The prune task is not started (M6). Shutdown cancels the scheduler; a running pipeline thread finishes the current unit and stops at the next deadline check.

## 9. Error mapping

| Condition | Pipeline error / HTTP | `code` | `retryable` |
|---|---|---|---|
| TAP returns zero exposures | `failed` event | `no_coverage` | false |
| TAP unreachable after retries; all fetches failed | `failed` event | `upstream_unavailable` | true |
| Deadline exceeded | `failed` event | `timeout` | true |
| Export validation failure; unexpected exception | `failed` event | `internal_error` | false |
| Server restart during a job | `failed` event | `internal_error` | true |
| Some fetches failed permanently | `complete` with `result_status = "partial"` | — | — |
| Gaia unavailable | `warning gaia_unavailable`, `gaia.json` verdict `unavailable` | — | — |
| Request validation | HTTP 422 | `invalid_request` | — |

## 10. CLI (`cli.py`, entry point `spherex`)

Global options: `--config PATH` (default `backend/config.yaml`), `--log-level LEVEL`.
Exit codes: `0` success, `2` usage error, `3` validation or contract failure, `4` upstream failure, `5` no coverage.

| Command | Behavior |
|---|---|
| `spherex serve [--host H] [--port P]` | Start Uvicorn with one worker and the application of §8 |
| `spherex contract extract [--from FILE] [--out DIR]` | Extract the JSON Schema blocks of `DATA_CONTRACT.md` into `schemas/v1/` |
| `spherex channels build --source PATH_OR_URL [--out FILE]` | Read the `SPECTRAL_CHANNELS` table from a SPHEREx HiPS cube tile or its metadata, write the 102-row `channels.json` (columns of `§C 5.1` `channels`); exits `3` unless exactly 102 rows are produced |
| `spherex targets resolve [--slug S ...]` | For each `tier1_targets` entry with `resolve: gaia`: (1) `SkyCoord.from_name(resolver_name)` gives a name-resolver position, treated as epoch 2000.0; (2) cone-search Gaia with `gaia_search_radius_arcsec`; (3) propagate each source to 2000.0 with its own proper motion (zero motion when null) and pick the one closest to the resolver position; (4) require separation ≤ `resolve.max_separation_arcsec`, else exit `3` naming the slug; (5) write `{slug: {input_ra_deg, input_dec_deg, coord_epoch_year (Gaia ref_epoch), pmra_mas_yr, pmdec_mas_yr, parallax_mas, pm_source: "gaia_dr3", pm_reference: "gaiadr3.gaia_source:<id>"}}` to `paths.resolved_targets_file` |
| `spherex targets verify` | Compare `tier1_5_targets` coordinates and the WISE 0855 position of config against a TAP discovery: reports, per target, `n_exposures` and exits `3` if any returns zero |
| `spherex build [--slug S ...] [--tier tier1\|tier1_5\|all] [--force]` | Run `run_pipeline` for the selected configured targets with a console sink; skips a target whose `data/{slug}/meta.json` exists unless `--force`; prints a summary (frames, epochs, failures, seconds) |
| `spherex build-coord --ra DEG --dec DEG [--size DEG] [--name TXT] [--pmra MAS] [--pmdec MAS] [--epoch YEAR] [--force]` | Run the Tier 2 pipeline synchronously for a coordinate; prints the slug |
| `spherex update [--tier tier1\|tier1_5\|all]` | Re-run discovery for selected targets; when the new `data_version` equals the stored one, print `unchanged` and stop; otherwise rebuild (cached cutouts are reused, so only new exposures are downloaded) and publish atomically |
| `spherex warm --file PATH` | Specified: read lines `ra_deg dec_deg [size_deg]`, run `build-coord` for each. Not implemented (M6); exits 3. Pre-warming is `scripts/prewarm.ps1` |
| `spherex validate [PATH \| --slug S \| --all]` | Run `contract_check.validate_directory`; print violations; exit `3` on any |
| `spherex probe irsa --ra DEG --dec DEG` | Run a TAP discovery and one cutout fetch; print timings, row counts, response headers, and the result of an `OPTIONS` request with an `Origin` header (informational) |
| `spherex probe gaia --ra DEG --dec DEG` | Run the Gaia cone query; print the selected columns and timing |
| `spherex jobs prune` | Specified: run the prune routine of §7.2 once. Not implemented (M6); exits 3 |

## 13. Test plan

Network access is abstracted by `DiscoveryClient`, `GaiaClient` and the cutout fetcher; tests inject fakes serving recorded fixtures from `tests/fixtures/`.

### 13.1 Unit

| Area | Cases |
|---|---|
| `timeutil` | `mjd_to_year(51544.5) == 2000.0`; propagation of a known proper motion over a known interval; RA wrap |
| `grid` | Widths 30 / 60 / 118 for sizes 0.05 / 0.1 / 0.2; `world_to_pixel` equals the astropy WCS to 1e-6 px; round trip through `pixel_to_world`; orientation (east at low `x`, north at high `y`) |
| `binfmt` | The `§C 10.3` vector decodes to `[1, −1, NaN, 65504, −65504, 0, 0.5, 2]`; clipping counts saturated values; plane-1 NaN iff plane-0 NaN; byte length `n × 2 × H × W × 2`; little-endian bytes |
| `discovery` | Release filtering; de-duplication by `(vnum, year, doy)`; invalid `mjd` dropped; `t_mid`; rediscovery threshold |
| `fetch` | Retry/backoff sequence with `on_retry` calls; cache hit; backfill pass; exhausted failure bookkeeping |
| `parse`/`frames` | Flag fractions and `contamination_level` for synthetic flag planes; bad mask equals `712439` semantics; wavelength min/max; `nearest_channel` ties |
| `group` | Epoch clustering at the gap boundary; single-linkage chaining |
| `coadd` | Inverse-variance mean and `σ̄` on synthetic frames; NaN handling; `snr_target`; scope keys and ordering; `detector_rgb` partition and tie rules; `equal_channel_rgb` constants (33/33/34 channels, excluding 50 and 51); `feature_lines` clipping at the ends |
| `photometry` | Known-flux Gaussian source on a flat background recovered within tolerance; null rules for empty aperture or annulus; `1e9` unit conversion |
| `centroid` | Known sub-pixel offset; null triple rules; deterministic Monte-Carlo (same seed → same error) |
| `pmfit` | Synthetic linear motion recovered; null below 3 epochs or 300 days; consistency flag |
| `gaia` | Cone-radius rule; separation and primary selection; adoption fixed point including the revert path; verdict table |
| `api` | Slug function (golden values); 400/415/422/429/404 envelopes; 200 vs 202; `joined`; strict types |
| `events` | Sequence ids; replay with `Last-Event-ID`; keep-alive; termination after terminal event |

### 13.2 Integration

1. **Synthetic end-to-end.** A fake IRSA/Gaia pair produces a small set of synthetic cutouts (known star, known mover, known flags). The pipeline runs to completion; the output passes `validate_directory`; the mover's measured proper motion matches the injected value; Gaia verdict is `match_consistent`.
2. **Partial result.** One cutout fails permanently → `result_status = "partial"`, `n_failed_fetches = 1`, `failed_source_uris` populated, `meta.status = "partial"`.
3. **No coverage.** Empty TAP result → `failed` / `no_coverage`.
4. **SSE order.** The recorded event sequence matches `§C 12.2`; frame events decode (`pixels.data`) to the bytes at the same `frame_key` in `frames.bin` (after matching by `frame_key`).
5. **Cache and join.** Two identical `POST` requests during a run produce one job (`joined = true`); a request after completion returns `200` with `cached = true` and a replayable stream.
6. **Static service.** ETag, conditional request, immutable caching with `?v=`, gzip on JSON only, 404 for a directory without `meta.json`.
